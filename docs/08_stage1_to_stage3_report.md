## 结论摘要

前三阶段已形成一次完整、可复现的闭环：文献与项目调研 → 官方数据下载与预处理 → Qwen LoRA 训练 → 固定验证集前后对比。

在 LaMP-7 官方验证集固定的前 100 条上，Qwen3-1.7B 的 LoRA 适配器相对同一基座取得：BLEU 11.93 → 17.26、chrF 37.05 → 39.52、ROUGE-L 0.401 → 0.448。所有参考文本指标均上升，但部分表层风格特征误差没有同步改善，因此不能仅凭本轮结果宣称“个性化风格已经完全学会”。

### 预处理原则

- 完整保留官方 train/dev/test，不重新随机切分。
- 使用 HTML 实体解码和 Unicode NFKC 规范化。
- 将账号、URL、邮箱和电话号码替换为占位符，不编写或补造文本。
- 每条任务从已有用户历史中按词汇 Jaccard 相似度选择 8 条相关风格示例。
- 以固定种子 `20251206` 构建严格嵌套的 50/100/200/500 条训练子集。
- 保存原始文件 SHA-256、抽样 ID SHA-256、数据计数和配置。
- 原始与处理后文本均位于 Git 忽略目录，避免误提交受许可约束的语料。

处理报告位于 `data/processed/lamp7/dataset_report.json`，处理程序为 [`lamp7.py`](../src/personal_llm_data/lamp7.py) 和 [`prepare_lamp7.py`](../scripts/prepare_lamp7.py)。

LoRA 后的文本更接近参考答案，例如更常保留账号占位符、口语缩写、标点和社交媒体表达。另一方面，长度 MAE 从 19.55 上升到 20.90，uppercase-rate MAE 也上升；因此后续需要加入风格分类器、语义相似度、人工盲评和置信区间，而不能只报告 BLEU/ROUGE。

## 当前结论边界

本轮已经证明：在 500 条 LaMP-7 样本、0.504% 可训练参数和约 4.72 GiB 峰值显存下，Qwen3-1.7B 的 LoRA 训练可在消费级 GPU 上稳定完成，并明显提高参考文本匹配指标。

尚未证明：该收益在 50/100/200 条、其他 rank、QLoRA、GYAFC、中文数据或人工风格判断上仍然成立。以上内容属于第四阶段消融与多维评估任务。

## 第四阶段建议顺序

1. 固定当前代码，运行 50/100/200/500 数据量消融，并报告三次随机种子均值与标准差。
2. 比较 rank 4/8/16，避免同时改变学习率等其他变量。
3. 增加 QLoRA 4-bit，对比显存、速度和质量。
4. 完成 GYAFC 授权后复现实验，验证结论是否跨数据集成立。
5. 增加语义相似度、风格分类准确率、人工盲评和通用指令回放测试。
