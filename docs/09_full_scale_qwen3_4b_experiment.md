# Qwen3-4B 全规模个性化 LoRA 实验报告

执行日期：2026-10-16 至 2026-10-19  
项目：基于低资源微调的大模型个性化适配方法探索（20251206）

## 1. 本轮完成情况

本轮不再使用 50–500 条样本或简化模型作为最终结果，而是在单张消费级 GPU 上完成：

- 基座模型：Qwen3-4B；
- 训练数据：LaMP-7 官方训练集全部 10,437 条；
- 测试数据：LaMP-7 官方测试集全部 1,496 条；
- 方法：BF16 LoRA，rank 16，注意力层和 MLP 层均注入适配器；
- 对照：基座/LoRA × 无用户画像/有用户画像，共四个条件；
- 评价：BLEU、chrF、ROUGE-1/2/L、BERTScore、精确匹配；
- 推断检验：2,000 次配对 bootstrap，并检验 LoRA 与用户画像的交互效应。

这使项目从“流程跑通”进入“有完整测试集、对照组和统计区间的正式实验”阶段。

## 2. 数据与预处理

### 2.1 数据范围

| 划分 | 官方样本数 | 本轮使用数 | 用途 |
|---|---:|---:|---|
| train | 10,437 | 10,437 | LoRA 训练 |
| dev | 1,500 | 500 | 每轮验证和最佳 checkpoint 选择 |
| test | 1,496 | 1,496 | 最终四条件评价 |

三个划分沿用 LaMP-7 官方划分，没有重新随机混合。问题与输出按 ID 一一核验，缺失 ID 为 0。原始文件 SHA256 和子集 ID 哈希保存在 [`dataset_report.json`](../data/processed/lamp7_bm25_k12/dataset_report.json)。

### 2.2 用户画像检索

每个样本只从该样本随附的用户历史中检索，不跨用户共享历史。处理流程为：

1. 去除查询中重复出现的任务说明，保留待改写文本；
2. 对用户历史建立样本内 BM25 索引；
3. 采用 `k1=1.5`、`b=0.75`，选取相关度最高的 12 条历史；
4. 保存检索分数、原始画像大小和检索方法元数据；
5. 将画像、当前任务和目标输出转换成 Qwen chat messages；训练损失只计算 assistant 输出。

该做法比早期 Jaccard 词集重叠更能处理词频和文本长度差异。完整实现位于 [`lamp7.py`](../src/personal_llm_data/lamp7.py)，处理结果位于 `data/processed/lamp7_bm25_k12/`。

所有生成均使用确定性解码，四个条件使用相同的 1,496 个测试 ID 和相同参考答案。

| 条件 | BLEU | chrF | ROUGE-1 | ROUGE-2 | ROUGE-L | BERTScore F1 |
|---|---:|---:|---:|---:|---:|---:|
| 基座，无画像 | 11.694 | 37.230 | 0.4695 | 0.2139 | 0.4099 | 0.3914 |
| 基座，有画像 | 15.025 | 40.055 | 0.4973 | 0.2423 | 0.4340 | 0.4183 |
| LoRA，无画像 | 17.102 | 41.078 | 0.5419 | 0.2748 | 0.4814 | 0.4500 |
| **LoRA，有画像** | **24.707** | **45.562** | **0.5784** | **0.3190** | **0.5197** | **0.4892** |

最强条件是“LoRA + 用户画像”。与“基座 + 用户画像”相比，它提高 BLEU 9.682、chrF 5.507、ROUGE-L 0.0857、BERTScore F1 0.07085。四个条件均无空输出。

## 5. 配对 bootstrap 与交互效应

bootstrap 以测试样本为配对重采样单位，随机种子为 20251206。下表报告观察差值及 95% 百分位区间。

| 对比 | BLEU 差值 [95% CI] | chrF 差值 [95% CI] | ROUGE-L 差值 [95% CI] |
|---|---:|---:|---:|
| LoRA 效应（有画像） | 9.682 [8.773, 10.589] | 5.507 [4.818, 6.190] | 0.0857 [0.0786, 0.0926] |
| LoRA 效应（无画像） | 5.408 [4.857, 5.970] | 3.848 [3.385, 4.316] | 0.0715 [0.0655, 0.0778] |
| 画像效应（LoRA） | 7.604 [6.540, 8.703] | 4.484 [3.744, 5.265] | 0.0383 [0.0311, 0.0455] |
| 画像效应（基座） | 3.331 [2.581, 4.142] | 2.824 [2.333, 3.336] | 0.0241 [0.0183, 0.0303] |
| **LoRA × 画像交互** | **4.273 [3.354, 5.202]** | **1.659 [0.953, 2.401]** | **0.0142 [0.0063, 0.0220]** |

以上区间均不跨 0；2,000 次重采样中差值大于 0 的比例均为 1.000。

BERTScore 使用 `roberta-large`、IDF 权重和 baseline rescaling。在语义指标上，LoRA × 画像交互为 **0.01222 [0.00400, 0.02027]**，2,000 次重采样中大于 0 的比例为 0.999。词面指标和上下文化语义指标因此给出了方向一致的证据。

## 6. 全测试集误差分析

逐样本 ROUGE-L 对比显示，LoRA + 画像相对基座 + 画像为 **1,108 胜 / 64 平 / 324 负**，排除平局后的胜率为 **77.37%**。画像对 LoRA 的逐样本作用为 801 胜 / 207 平 / 488 负，排除平局后的胜率为 62.14%。这说明总体增益不是由极少数异常样本拉动，但仍存在约五分之一测试样本上的 LoRA 回退，不能只看均值。

按参考答案词数分层后，LoRA + 画像相对基座 + 画像的平均 ROUGE-L 增益分别为：

| 参考答案长度 | 样本数 | LoRA 增益 |
|---|---:|---:|
| 最短四分位（≤12 词） | 416 | +0.1120 |
| 第二四分位（13–16 词） | 333 | +0.0837 |
| 第三四分位（17–21 词） | 376 | +0.0724 |
| 最长四分位（>21 词） | 371 | +0.0714 |

四个长度层均为正，但短输出收益更大，提示长文本的内容保持和风格控制仍有改进空间。

按原始用户历史规模分层，LoRA 增益在 1–10、11–20、21–50、51+ 四组分别为 +0.0836、+0.0842、+0.0932、+0.0852。画像对 LoRA 的额外增益在前三组约为 +0.0374、+0.0377、+0.0479；51+ 组为 -0.0010，但该组只有 47 条，因此这里只把它作为“固定 BM25 top-12 可能不足以覆盖超长画像”的待验证信号，不作显著性结论。

机器可读的分层统计以及最大回退/提升样本 ID 位于 `error_analysis.json`，可据此开展盲法人工错误分类，同时避免在研究报告中公开复述原始用户文本。

## 7. 可以得出的结论

1. **LoRA 确实学到了任务映射。** 即使推理时移除用户画像，LoRA 仍显著优于无画像基座，说明收益不是单纯复制检索文本。
2. **用户画像本身有效。** 不训练适配器时，加入检索画像也能提高所有主要指标。
3. **LoRA 与画像存在正交互。** 画像对 LoRA 模型的增益显著大于对基座的增益，支持“微调让模型学会更有效利用个性化历史”的解释。
4. **单卡消费级训练可行。** 4B 模型、完整训练集、覆盖注意力与 MLP 的 rank-16 LoRA 在约 9.50 GiB 峰值显存下完成，不需要用极小数据来替代正式实验。

## 8. 不能过度解释的部分

- 本轮相对早期 1.7B/500 条基线同时改变了模型规模、数据量、检索器和 LoRA rank，因此不能把总体提升单独归因于“4B”或“全量数据”。这需要后续受控因子实验。
- 自动指标衡量与参考输出的接近程度，并不等同于真实用户偏好。仍需盲法人工评分或经过偏差控制的 LLM-as-a-Judge。
- 当前正式任务是英文 tweet 个性化改写；结论尚不能直接外推到中文写作、长文本或领域知识注入。
- 验证只使用固定的 500 条 dev 样本以控制训练开销；正式论文应补做完整 dev 检查或证明该子集稳定。
- 当前使用 BF16 LoRA，尚未与 NF4 QLoRA 做同设置对照，因此还不能报告量化带来的性能—资源权衡。

## 11. rank 8 受控容量消融（2026-10-19）

为分离 LoRA 容量的影响，新增 rank 8、alpha 16 对照；除 rank 与 alpha 外，其余模型、数据、检索、精度、目标层、优化参数、训练轮数、验证子集和随机种子均与 rank 16 正式实验一致，且保持 `alpha/r=2`。rank 8 可训练参数为 16,515,072（0.40889%），适配器权重约 63 MiB；训练用时 11,239.18 秒，峰值显存约 9.26 GiB。两轮 dev loss 为 1.75419、1.75101，最佳权重来自第 2 轮。

完整 1,496 条测试集上，rank 8 无画像条件得到 BLEU 16.904、chrF 40.515、ROUGE-L 0.4797、BERTScore F1 0.4452；有画像条件得到 BLEU 24.372、chrF 44.955、ROUGE-L 0.5135、BERTScore F1 0.4835，所有输出均非空。与 rank 16 有画像结果相比，rank 8 的 BLEU、chrF、ROUGE-L 和 BERTScore F1 分别低 0.334、0.607、0.00615 和 0.00565。

严格的 2,000 次原始语料级配对 bootstrap 显示，rank 8 减 rank 16 的 BLEU 差值为 -0.334，95% CI [-0.698, 0.033]；chrF 为 -0.607，95% CI [-0.969, -0.230]；ROUGE-L 为 -0.00615，95% CI [-0.01044, -0.00177]。因此 BLEU 差异尚不确定，但 chrF 和 ROUGE-L 对 rank 16 的小幅优势给出一致证据。综合质量与存储成本，rank 8 是资源更紧张时的可用备选，rank 16 仍保留为当前质量优先基线。

rank 8 的机器可读产物位于 `experiments/runs/qwen3-4b-lamp7-full-lora-r8-a16/`，包括 `training_summary.json`、两组完整预测与指标、`bertscore.json` 和 `paired_r8_vs_r16_profile_bootstrap.json`。

## 12. rank 32 受控容量消融（2026-10-20）

rank 32、alpha 64 沿用同一 Qwen3-4B 模型、10,437 条训练数据、500 条固定 dev 子集、BM25-k12 画像、BF16、学习率 `1e-4`、有效 batch 16、两轮训练、全部注意力与 MLP 目标层及种子 `20251206`，保持 `alpha/r=2`。可训练参数为 66,060,288（1.61575%），适配器权重 264,308,896 bytes（约 252 MiB）。训练用时 12,713.31 秒，峰值 GPU 显存 10,790,898,176 bytes（约 10.05 GiB）。第 1、2 轮 dev loss 为 1.74014、1.76032；第 1 轮 checkpoint-653 为最佳，最终适配器 SHA256 与其一致：`3B3200E8E37675DE9C7CAF9FE33B2BDAE00D09FA8277D0B976850D3335FB426B`。第 2 轮虽降低训练损失，却使 dev loss 明显回升，提示在更大容量下过拟合更强。

在全部 1,496 条官方测试样本上，rank 32 无画像得到 BLEU 17.304、chrF 41.133、ROUGE-1/2/L 0.5429/0.2760/0.4830、BERTScore F1 0.4512；有画像得到 BLEU 24.651、chrF 45.338、ROUGE-1/2/L 0.5747/0.3160/0.5167、BERTScore F1 0.4831。BERTScore 使用 `roberta-large`、IDF 和 baseline rescaling。两条件均与冻结的基座预测使用相同测试 ID 和参考答案。rank 32 有画像条件出现 1 条空输出（ID `621209`，1/1,496）；该异常保留在正式结果中，未过滤。

与 rank 16 的有画像条件相比，2,000 次原始语料级配对 bootstrap（每次重新计算 `corpus_score`）得到：BLEU 差值 -0.055，95% CI [-0.284, 0.167]；chrF -0.224，95% CI [-0.492, 0.042]；ROUGE-L -0.00301，95% CI [-0.00608, 0.00001]。三项区间均跨 0，不能断言 rank 32 在这些指标上优于或劣于 rank 16。BERTScore F1 观察值低约 0.0061，但尚未对该差异做配对置信区间。逐样本 ROUGE-L 对比 rank 32 有画像与基座有画像为 1,094 胜 / 63 平 / 339 负；画像对 rank 32 的逐样本作用为 787 胜 / 217 平 / 492 负。超过 50 条原始历史的 47 个用户样本中，画像平均增益为 -0.0096，仅作探索性信号，不作显著性结论。

三档 rank 形成的当前证据是：rank 8 节省参数与存储，但 chrF、ROUGE-L 略低于 rank 16；rank 32 的最佳 dev loss 略低，却未转化为有把握的测试提升，并增加训练时间、显存和适配器存储。故质量优先配置暂保留 rank 16、alpha 32。以上仅为单训练种子和单任务结论；下一步固定 rank 16 单独比较 alpha 16/32/64，再进行多种子、量化、数据量、检索与通用能力保持实验。rank 32 的训练摘要、两组逐条预测、指标、BERTScore、错误分析及 bootstrap 结果位于 `experiments/runs/qwen3-4b-lamp7-full-lora-r32-a64/`。

## 13. rank 16、alpha 16 缩放消融（2026-10-25）

本实验固定 Qwen3-4B、rank 16、10,437 条训练数据、500 条固定 dev、BM25-k12、BF16、学习率 `1e-4`、有效 batch 16、两轮训练、全部注意力与 MLP 目标层及种子 `20251206`，只把 alpha 从正式基线的 32 改为 16。训练按用户要求在第二轮暂停，随后从 checkpoint-653 恢复模型、优化器、学习率调度器和 RNG 状态。第 1、2 轮 dev loss 为 1.75509、1.75077，最佳权重来自第 2 轮；最终适配器 SHA256 为 `6E455145F667E84FCC537DE56C37B518166B9F39B52407567A01B2EEF1DE4431`，与 checkpoint-1306 一致。恢复阶段用时 5,204.56 秒，峰值显存 10,201,278,976 bytes（约 9.50 GiB）。摘要时间不包含暂停前的第一轮，故不用于训练速度横向比较。

完整 1,496 条测试集上，alpha 16 无画像得到 BLEU 16.969、chrF 40.506、ROUGE-1/2/L 0.5391/0.2736/0.4791、BERTScore F1 0.4456；有画像得到 BLEU 24.396、chrF 45.000、ROUGE-1/2/L 0.5739/0.3110/0.5137、BERTScore F1 0.4827。两组均无空输出。BERTScore 使用 `roberta-large`、IDF 和 baseline rescaling；其 LoRA×画像交互为 0.01015，95% CI [0.00099, 0.01906]，表明在该配置下微调仍提高了模型利用画像的能力。

相对 alpha 32 正式基线，2,000 次原始语料级配对 bootstrap 得到 alpha 16 的有画像 BLEU 差值 -0.310，95% CI [-0.644, 0.019]；chrF -0.562，95% CI [-0.915, -0.200]；ROUGE-L -0.00601，95% CI [-0.01009, -0.00188]。BLEU 区间跨 0，但 chrF 与 ROUGE-L 均支持 alpha 32 的小幅优势。有画像 BERTScore F1 观察值亦低约 0.0065。逐样本 ROUGE-L 中，alpha 16 有画像相对基座有画像为 1,052 胜 / 64 平 / 380 负；画像对 alpha 16 为 808 胜 / 170 平 / 518 负。四个参考长度层以及四个原始画像规模层中的 LoRA 平均增益均为正。

因此，减小缩放强度没有改善泛化，现有单种子证据不支持 alpha 16 替换 alpha 32。机器可读训练摘要、两组完整预测、BERTScore、错误分析和配对结果位于 `experiments/runs/qwen3-4b-lamp7-full-lora-r16-a16/`。alpha 64 的补充对照见下一节。

## 14. rank 16、alpha 64 缩放消融（2026-10-26）

本实验沿用全量 10,437 条训练数据、500 条固定 dev、两轮 BF16 LoRA、rank 16、学习率 1e-4、有效 batch 16、BM25-k12、全部注意力与 MLP 目标层以及种子 20251206，仅将 alpha 改为 64。训练共 1,306 步，用时 8,554.22 秒，峰值分配显存 10,205,880,320 bytes（约 9.50 GiB）。两轮 dev loss 为 1.74139595、1.76266611，最佳为第一轮 checkpoint-653；最终适配器与该 checkpoint 的 SHA256 一致：`C09AD1F82269D02FFC49E8EE9334D75087C52E15530C5D5EFC0313319DC146AA`。第二轮 dev loss 回升，故最终评价使用第一轮最佳权重。

完整 1,496 条测试集的无画像条件得到 BLEU 17.605、chrF 41.368、ROUGE-1/2/L 0.5429/0.2778/0.4833、BERTScore F1 0.4530；有画像条件得到 BLEU 24.712、chrF 45.698、ROUGE-1/2/L 0.5789/0.3193/0.5204、BERTScore F1 0.4923。两条件均无空输出，ID 与参考答案同冻结基座预测一致。BERTScore 使用 roberta-large、IDF 和 baseline rescaling，其 LoRA×画像交互为 +0.01231，95% CI [0.00437, 0.02025]。有画像适配器相对有画像基座的逐样本 ROUGE-L 为 1,104 胜 / 59 平 / 333 负；画像对适配器为 805 胜 / 212 平 / 479 负。

有画像条件下，alpha 64 减 alpha 32 的 2,000 次原始语料级配对 bootstrap 为：BLEU +0.00510，95% CI [-0.30604, 0.27381]；chrF +0.13646，95% CI [-0.15176, 0.41865]；ROUGE-L +0.000718，95% CI [-0.002182, 0.003657]。三个区间均跨 0，现有单种子证据不足以确认 alpha 64 的测试优势，也不能解释为等效检验通过。BERTScore 的配置间观察差约为 +0.0031，尚未单独计算该差异的置信区间。

至此 alpha 16/32/64 的训练与既定全测试评价协议均已完成。alpha 16 的 chrF 与 ROUGE-L 略低于 alpha 32；alpha 64 的最佳 dev loss 为三档中最低，因此按 dev 规则列为完整 dev 与多种子复验候选。后续数据规模实验沿用预先固定的 alpha 32，避免同时改变研究因素。所有 alpha 64 机器可读产物位于 `experiments/runs/qwen3-4b-lamp7-full-lora-r16-a64/`，包括训练摘要、两组完整预测、指标、BERTScore、错误分析及 `paired_alpha64_vs_alpha32_profile_bootstrap.json`。

## 15. 数据规模消融的首档结果（2026-10-26）

固定 rank 16、alpha 32 及其余设置，开始 50/100/200/500/2,000/10,437 条嵌套训练集实验。子集的计数、唯一 ID、嵌套关系和记录与全量 train 的内容一致性均已检查通过。50 条模型两轮共 8 次 optimizer 更新，dev loss 从 3.10674 降至 2.48014；最终适配器哈希与第二轮最佳权重一致。完整 1,496 条测试集上，无画像得到 BLEU 11.946、chrF 37.073、ROUGE-L 0.4086、BERTScore F1 0.3906；有画像得到 BLEU 15.673、chrF 36.781、ROUGE-L 0.3898、BERTScore F1 0.3480。两组均无空输出，测试 ID 和参考答案与冻结基座一致。

50 条相对全量模型有画像条件的 2,000 次原始语料级配对 bootstrap 得到 BLEU -9.034，95% CI [-9.881, -8.191]；chrF -8.781，95% CI [-9.529, -8.032]；ROUGE-L -0.12985，95% CI [-0.13882, -0.12108]。BERTScore 上画像对 50 条模型的作用为 -0.04264，95% CI [-0.05374, -0.03198]，显示该配置出现了利用画像能力的回退。不能只根据有画像 BLEU 略高于基座而宣称微调有效。

当前实验固定两轮，小样本同时意味着较少更新次数，因此不能单独将回退归因为数据量；后续需要用 dev 另行检验训练轮数或等更新预算。完整的进度、限制和机器可读结果入口见 `docs/12_data_scale_experiment.md`。
