# 个性化适配综合评价协议

更新日期：2026-10-26

## 1. 评价对象与冻结规则

每个正式配置在 LaMP-7 全部 1,496 条测试样本上使用确定性解码。测试 ID、参考答案、最大输入长度、最大生成长度和解码参数在首次正式实验后冻结；模型选择只使用 dev loss，不根据 test 结果反复调整训练设置。

基础设计为“基座/LoRA × 无画像/有画像”2×2对照。rank、alpha、数据规模、量化和模型规模实验一次只改变一个因素。主要配置至少运行三个训练随机种子；bootstrap重采样不能替代多次独立训练。

## 2. 自动评价

逐参考指标包括 BLEU、chrF、ROUGE-1/2/L和BERTScore。每个指标均报告完整测试集分数、相对固定基线的差值和配对置信区间。BLEU和chrF的2,000次bootstrap必须在每个重采样中重新计算语料级指标，ROUGE-L按逐样本F1均值计算。

自动指标还需报告空输出率、输出长度误差、问号/感叹号/省略号/大写比例误差，并按参考答案长度、原始画像规模及检索得分分层。分层分析是探索性分析；样本量较小的组不得只凭均值下显著性结论。

当前消融结果的 95% 区间为逐比较的百分位 bootstrap 区间，未进行多重比较校正；用于描述各预定对比的不确定性，不代表对全部实验矩阵同时控制 5% 错误率。单训练种子的测试样本 bootstrap 不包含训练随机性。正式确认性结论须结合预先指定的主要比较、独立训练种子和完整 dev 检查；置信区间跨 0 仅表示本次检验未明确区分方向，不能当作等效性证明。

## 3. 人工盲评

从冻结测试集中按参考答案长度和原始画像规模联合分层抽取200条样本。每条展示原始改写请求、对应用户画像和匿名化的系统输出，不展示模型名称和自动指标。系统顺序按固定随机种子打乱，映射表与评分表分开保存。

每条输出按1–5分评价四个维度：

1. 内容保持：是否保留原请求的事实、实体、态度和关键约束；
2. 风格相似：措辞、大小写、标点、句法、语气和表达习惯是否接近画像；
3. 流畅自然：是否通顺、连贯且不存在不必要重复；
4. 指令遵循：是否只返回改写文本，且没有解释、拒答或额外内容。

另做A/B成对偏好，可选择A、B或平局。每条至少由两名评价者独立标注；若资源允许，使用三名评价者。报告各维度均值、置信区间、成对胜负率，以及加权Cohen's kappa或Krippendorff's alpha。分歧样本由第三人复核，但原始独立评分必须保留。

## 4. LLM-as-a-Judge

LLM裁判采用与人工评价相同的四维rubric，不提供模型身份。每个样本至少评价两次，并交换A/B位置；位置交换后结论不一致的样本记为不稳定，不强行判胜。最终同时报告原始胜率、位置一致率和去除不稳定样本后的胜率。LLM评分只作为人工评价的补充，不能替代人工结论。

## 5. 通用能力与遗忘

在加载和不加载适配器的条件下，使用相同提示模板评价通用指令遵循、常识与基础推理。优先采用有明确许可证和固定答案的公开基准，并在首次运行前锁定版本、样本ID和评分脚本。报告适配器相对基座的绝对差值；如果个性化指标上升但通用能力显著下降，应视为适配失败而不是单纯性能提升。

## 6. 错误分类

对LoRA相对基座回退最大的样本进行人工错误标注，类别包括：语义改变、关键信息遗漏、实体错误、画像内容误复制、风格过度模仿、风格不足、输出过长或过短、检索不相关、语言不流畅和指令格式错误。错误分类结果用于形成下一轮假设，不直接用于修改冻结测试集。
