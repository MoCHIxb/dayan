# Qwen3-4B 数据规模受控消融

更新日期：2026-10-26。六档数据规模的单种子固定两轮训练与既定完整测试评价均已完成。

## 固定设置与数据核验

固定 Qwen3-4B、BF16 LoRA、rank 16、alpha 32、BM25-k12、种子 20251206、两轮训练、学习率 1e-4、有效 batch 16、max_length 768 和全部注意力及 MLP projection。dev 使用与正式基线一致的固定 500 条；每个已评价配置均使用全部 1,496 条冻结 test，并分别运行有画像和无画像条件。确定性生成设置为 batch 4、输入上限 768、输出上限 80 token。基座两组预测复用已有正式结果。

训练数据量依次为 50、100、200、500、2,000、10,437 条。五个小子集均已检查记录数、唯一 ID、小集合对较大集合的包含关系以及记录内容与全量 train 的逐行一致性，全部通过。配置 `configs/qwen3_4b_lamp7_n{50,100,200,500,2000}_lora_r16_a32.json` 与全量基线只在 train_file 和 output_dir 上不同。

固定 epoch 不等于固定计算预算：不同数据量的 optimizer step 数不同，50 条共 8 步，全量共 1,306 步。当前曲线回答的是“固定两轮训练协议下增加训练数据的效果”，不能分离数据多样性和更新次数的独立贡献。对少样本方案的最终优化仍需另外使用 dev 比较训练轮数或等更新步数；不得把当前失败结果解释为 50 条数据永远无法适配。

## 已完成的 100 条数据档

已完成 100 条训练、500 条固定 dev、两轮共 14 步。第 1、2 轮 dev loss 为 2.31885815/2.20541167，最佳为第二轮 checkpoint-14；最终适配器 SHA256 与最佳 checkpoint 一致：`09CC1BB8D68711FA862FBBF67ECFFC26042E64C3273D0DF3188D4B817EE4C44C`。训练用时 166.26 秒，峰值分配显存 9,764,580,352 bytes（约 9.09 GiB）。两种测试条件均包含 1,496 个唯一 ID，参考答案与基座一致，均无空输出。完整生成、BERTScore、错误分析和原始配对 bootstrap 均已完成。

100 条无画像条件相对无画像基座的 BERTScore F1 差值为 +0.00907，95% CI [0.00532, 0.01255]；画像对 100 条模型的 F1 作用为 -0.07585，95% CI [-0.08907, -0.06289]；LoRA×画像交互为 -0.10280，95% CI [-0.11559, -0.09054]。逐样本 ROUGE-L 中，有画像适配器相对有画像基座为 597 胜 / 71 平 / 828 负，画像对适配器为 586 胜 / 71 平 / 839 负。总体上无画像的任务映射有改善，但有画像生成出现明显回退。

100 条减全量的有画像 2,000 次原始语料级配对 bootstrap：BLEU -9.45845，95% CI [-10.36721, -8.57690]；chrF -10.25744，95% CI [-11.02720, -9.46523]；ROUGE-L -0.138681，95% CI [-0.147742, -0.129398]，三项区间均低于 0。100 条的有画像指标也低于 50 条的观察值，但尚未对这两个小样本配置单独检验，不能宣称数据增加导致可靠退化。记录负结果，继续既定曲线，不根据 test 更改训练配置。

## 已完成的 200 条数据档

已完成两轮共 26 步，训练记录 200 条、固定 dev 500 条；两轮 dev loss 为 2.12457919/2.03168559，最佳为第二轮 checkpoint-26。最终适配器与最佳 checkpoint SHA256 均为 `5F570B5CB27AD32BB2C5BD53023B9437E40068A67C4A449BE40DBC1D5CF243D9`。训练用时 232.46 秒，峰值分配显存 9,764,572,672 bytes。两种完整测试条件、BERTScore、误差分析和 2,000 次原始语料级配对 bootstrap 均已完成。两组各 1,496 条，唯一 ID 和参考答案检查通过，均无空输出。

200 条模型的有画像 BERTScore F1 为 0.43570，无画像为 0.41725；画像效应 +0.01845，95% CI [0.00951, 0.02735]。有画像相对有画像基座的 F1 效应 +0.01736，95% CI [0.00913, 0.02521]。然而 LoRA×画像交互仍为 -0.00849，95% CI [-0.01727, -0.00010]，说明画像对该适配器的增益仍弱于对基座的增益，尚不能认为个性化利用能力已达到全量模型水平。逐样本 ROUGE-L 上，有画像适配器相对有画像基座为 907 胜 / 97 平 / 492 负。

200 条减全量的有画像原始语料级配对 bootstrap 为 BLEU -5.46867，95% CI [-6.38501, -4.61878]；chrF -3.75439，95% CI [-4.42848, -3.08839]；ROUGE-L -0.056342，95% CI [-0.063263, -0.049425]，三项区间均低于 0。相比 50/100 条，观察值显示任务学习及画像利用恢复，但“收益拐点”仍需 500/2,000 条与多种子结果支撑。

## 已完成的 2,000 条数据档与曲线汇总

两轮共 250 步训练已完成，第 1、2 轮 dev loss 为 1.83969605/1.83361113，最佳为第二轮 checkpoint-250。最终适配器与最佳 checkpoint 的 SHA256 一致：`6F77B7A06A2823071009B240456F662B49CFF5E278BB3B95663000CA1FAFBF48`。训练记录 2,000 条、固定 dev 500 条，用时 1,607.23 秒，峰值分配显存 10,200,230,400 bytes。两种完整测试条件、BERTScore、误差分析与 2,000 次原始语料级配对 bootstrap 均已完成。全量档复用既有正式基线。

2,000 条模型的有画像 BERTScore F1 为 0.47250，无画像为 0.43776；画像效应 +0.03474，95% CI [0.02507, 0.04413]；LoRA×画像交互 +0.00780，95% CI [-0.00133, 0.01755]，区间跨 0。绝对分数提高不意味着交互必然更强。与 500 条之间尚未做专门配对比较，不能将交互观察值下降解释为可靠退化。逐样本 ROUGE-L 中，有画像适配器相对有画像基座为 1,056 胜 / 56 平 / 384 负。

六档曲线显示，50/100 条下画像利用回退，200 条后恢复正向收益，500 条出现正向交互证据；继续增加数据总体改善质量，但增益并非在所有指标和对比上严格单调。完整 dev、多种子和等更新预算实验仍待执行，当前结论限定于本协议。
