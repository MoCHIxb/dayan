# 客观风格与内容辅助证据协议 v1

日期：2026-11-02。该分析在本地test结果已可见后制定，属于探索性辅助分析，不是新的确认性实验，不调参、不改checkpoint、不替代完整主评价及既定原始bootstrap。

范围固定为500条训练条件下4配方×3种子，每个adapter有/无画像，以及BF16/NF4基座有/无画像，共28组完整1496条预测。保留43条参考答案在选中历史出现和1453条未出现的分组，所有分组仅作描述性敏感性分析。

## 表层风格证据

固定10个可解释特征：词数、平均词长、标点终止片段平均词数、首人称比例、次人称比例、缩写比例、字母大写比例、每百词感叹号/问号/逗号数。按真实train_500参考答案计算标准差作为尺度（零方差使用1，不利用test拟合），各维等权标准化绝对距离。画像是原BM25-k12历史特征均值，未声称等于截断后实际可见的全部历史。

计算输出对真实画像、参考答案的距离；另用seed20251206固定的无自配对画像记录置换作错配对照，报告“对错配画像距离减对真实画像距离”。这是既有输出的观察性比较，没有在错配画像下重新生成，不能解释为因果画像遵循，也不能将题目画像ID当真实用户ID。

这些特征包含长度和表层表达，不是完整句法分析；不能证明深层个人风格。标准化距离依赖预先写出的特征和尺度，不能以该分析在已见test上选择方案后宣称独立验证。

## 内容与复制风险

从原Task的首个冒号后提取待改写短文本，沿用既有分析规则。固定报告数字集合变化、否定标记出现状态变化、非功能词集合Jaccard、逐字输入复制、逐字历史复制和四元片段历史覆盖。数字/否定变化是风险标记，可能是合理改写或规则误报，不能计作事实错误率；同时报告参考答案相对输入的同类变化作为背景。

正式BLEU/chrF/ROUGE/BERTScore继续引用既有完整评价；补充分组BLEU/chrF每组调用原始corpus_score，不使用句分数平均。不给新辅助特征增加置信区间，不替代既定2000次原始配对bootstrap。词法Jaccard不等于语义保真，BERTScore不等于事实正确。
