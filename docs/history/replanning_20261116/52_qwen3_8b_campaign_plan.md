# Qwen3-8B主线完整实验方案（审阅稿）

2026-11-16。所有者要求后续实验以Qwen3-8B为主重新完整开展，先审阅方案。本文件覆盖50号中后续以4B开展的设计和51号的运行次数预算；不覆盖历史冻结协议或结果。这里只准备方案，没有冻结新队列、下载模型、生成可直接执行的训练配置或启动GPU。

## 1. 目标与范围

以Qwen3-8B重新建立完整的提示基线、数据量实验、多领域验证、PEFT取舍及成本报告，Llama-3-8B-Instruct保留为计划书要求的对照模型。4B结果保留用于历史参考，不作为任何8B实验的训练/预测复用。TF-IDF轻量结果不依赖LLM参数规模，只有实际输入、配置、预测与收据核对后可复用。

所有者已明确：全部历史实验也用Qwen3-8B重跑，包括LaMP、SMS和三领域安全。当前仍先准备方案，不立即启动GPU。下面54次是IntentTune主线子预算，已不代表全项目总量；历史模块与早期已完成研究清点见第7节。保留4B原协议/配置/结果，另立8B协议和输出。安全仅复用现有真实数据，不扩充来源，不恢复已取消VLM。

## 4. 提示与轻量比较、完整评价

每领域分别生成Qwen8B BF16零示例和固定10示例（每类1条，来自最小train）的完整test，三档训练共用同一提示参照，不重复算独立样本；每档TF-IDF只用该档train拟合词表/IDF/质心。BANKING的两基座另分别评价NF4与int8零示例，对适配器同时报告同精度基座参照与BF16参照。

所有54个适配器均完整评价各自test，保持原始ID/参考、条件/模型身份、命令和收据。每个新训练必须有完整128步、8次完整dev、最佳/最终checkpoint与导出哈希。训练状态文件、进程退出或单份分数都不足以宣布完成。

主指标macro-F1，另报accuracy、各类召回/最低召回、invalid及混淆。逐领域报告均值±SD与逐种子分数、相对各提示/轻量参照的差值。测试集不同条数不混池，不按test挑领域或种子。BANKING历史test已见，不称全新未见确认集。暂不追加新bootstrap或显著性/等效检验；原LaMP完整统计不改。

### 7.1 LaMP评价与统计完整保留

8B重新按dev选学习率与checkpoint，不继承4B的获胜学习率/最佳步。PEFT共同对照仅在新8B配方、种子、数据和资产完全匹配时复用；若500档新选学习率与历史PEFT固定1e-4不匹配，须在新8B协议中明确共同对照规则并补算必要训练预算，不能伪称相同对照或看test再决定。

保留BM25-k12真实数据、完整1500dev和1496test、画像/无画像、条件token加权NLL/PPL、BLEU/chrF/ROUGE、原roberta-large参考IDF＋rescale BERTScore、错误分层、复制、表层风格与43/1453原分组。输入768、输出80、batch4和原训练/生成截断规则是历史复现基准，8B tokenizer必须重新核查实际截断；不能声称仍恰好只有1条截断，不能删样本。若因兼容/显存需修改，另立差异版本，不冒充严格同配置复现。

用户要求完整既定统计：新8B预测必须在独立目录重新运行2000次原始corpus_score配对bootstrap，采用原算法、不用句级均值或充分统计近似替代。4B原有54项统计不重算、不覆盖。8B确切比较清单须在补齐早期8B对照和生成条件后固定；若完整复制原54项关系，须先有相应8B历史调度基线，不能把4B预测混作8B内部训练策略对照。跨4B/8B比较可另列，但须披露平台、tokenizer和训练配置差异。分类首轮仍不事后新增bootstrap/显著性或等效结论。

### 7.2 任务预算、覆盖与执行顺序

“统一8B”统一主基座、环境与证据契约，不意味着把所有任务改成100dev/128步/同一长度。LaMP、SMS、安全保留各自完整评价与原科学预算；安全32步功能验收与128步正式评价单独命名，三领域子组共用联合适配器，不伪装三次独立训练。暂停/恢复子进程不重复计为多个独立训练。

准备顺序：先完成全部历史完成证据清点与新8B配置映射，再冻结模型/数据/模板/评价和新统计清单；优先云端兼容、完整状态暂停恢复与资源预检，然后按任务分批串行执行。首轮18次IntentTune只是主线子阶段，不能以它完成宣布全项目重跑完成。完整总预算、预测量、统计量与磁盘/时间预算在清点和云端实测后再定，不据82次下界报价或一次自动排满。

所有新增实验只在云端3090显式执行。模型、原始文本、预测、checkpoint和私有传输仍不上传Git；完整结果与新8B证据另存，旧结果保持可追溯。论文按任务分别报告8B新结果与4B历史参考，不预设8B更好，不把更多实验数量当作创新。
